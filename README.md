# Clica, Compra e Ri

Site responsivo de achadinhos, ofertas e produtos virais.

## Rodar localmente

```bash
npm install
npm start
```

Abra http://localhost:3000

## Antes de publicar

1. Troque `SEU-DOMINIO.com` no `index.html`, `robots.txt` e `sitemap.xml` pelo domínio real.
2. Substitua os `url:'#'` no array `products` de `public/index.html` pelos links reais dos produtos/afiliados.
3. Troque os links das redes sociais no rodapé.
4. Revise a política de privacidade conforme as ferramentas de analytics, cookies e anúncios que forem instaladas.
5. Para Meta Pixel/Google Analytics, adicione os scripts somente depois de criar os IDs oficiais.
